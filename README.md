## 🌟 Overview

**Shlokh Entertainments (Shlokh Advertising & Branding)** is a premier creative production house based in **Punjagutta, Hyderabad (Telangana)** and **SVN Colony, Guntur (Andhra Pradesh)** with over 20+ years of creative leadership, 500+ documentaries & corporate films, and 100+ statewide public campaigns.

This web application is built with **React 19**, **Vite 8**, **Tailwind CSS**, and **Lucide Icons**, designed with an expansive, edge-to-edge luxury cinema layout tailored for both modern desktop screens (1080p, 1440p, 4K) and mobile devices.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18+ recommended)
- npm (v9+ recommended)

### Installation
```bash
git clone https://github.com/devpulseorg/shlok.git
cd shlok
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:8443](http://localhost:8443) in your browser.

### Production Build
```bash
npm run build
npm run preview
```
